# Преданализ ChatGPT: состояние и границы

## Источник

- Shared-ссылка: <https://chatgpt.com/share/6a6f198f-0844-83eb-886e-d76f79eaee23>.
- Назначение: дополнительный предварительный разбор книги, предоставленный пользователем вместе с FB3.
- Статус на 2026-08-02: содержимое shared-беседы не извлечено; ссылка и воспроизводимые признаки отказа сохранены.

## Что было проверено

| Маршрут | Результат |
| --- | --- |
| Публичный `backend-api/share` штатной утилитой | HTTP `403` |
| Публичная HTML-страница штатной утилитой | HTTP `403` |
| Автоматический loopback proxy-кандидат | соединение отклонено |
| Встроенный браузер Codex | не инициализировался из-за несовместимости локального WSL workspace URI |

Адреса, учетные данные и иные operational details сетевых маршрутов в dossier не записывались. Страницы отказа и пустые загрузки в Git не добавлены.

## Почему здесь нет реконструкции

Нельзя выдавать предположительный преданализ за содержимое shared-беседы. По ссылке неизвестны:

- исходный пользовательский запрос;
- тезисы и композиция ответа;
- embedded Research и его источники, если они были;
- возражения и уточнения пользователя;
- финальный редакторский вывод.

Поэтому остальные файлы dossier построены только по полному FB3, независимой проверке библиографических metadata и явно обозначенному редакторскому синтезу. Ни одно утверждение не атрибутировано недоступному преданализу.

## Как завершить включение

При восстановлении доступа повторить:

```bash
make extract-chatgpt CHATGPT_SHARE_URL="https://chatgpt.com/share/6a6f198f-0844-83eb-886e-d76f79eaee23"
```

Если ссылка останется недоступной, нужен экспорт или вложение видимого диалога. После получения текста требуется:

1. сохранить видимый диалог и embedded Research отдельно;
2. составить manifest и хэши;
3. сопоставить тезисы с `03-Аналитические-конспекты-глав.md`;
4. дополнить, а не заменить `06-Аудит-тезисов-и-доказательности.md`;
5. независимо проверить источники и конфликты интересов;
6. обновить `09-Состояние-сохранения.md`, реестр и обратные ссылки;
7. повторить link/privacy/evidence-аудит перед коммитом.

## Редакторская граница

Отсутствие преданализа не уменьшает техническую полноту обработки книги: сохранены все двенадцать глав, приложения, примечания, изображения и структурные metadata. Оно ограничивает только независимый второй ракурс. Пакет считается полным по FB3 и открытым по shared-беседе.

# Преданализ ChatGPT: состояние и границы

## Источник

- Shared-ссылка: <https://chatgpt.com/share/6a6f1203-39c0-83eb-9914-a8ad3a798504>.
- Назначение: дополнительный предварительный разбор книги, предоставленный пользователем вместе с FB3.
- Статус на 2026-08-02: содержимое shared-беседы не извлечено; ссылка и воспроизводимые признаки отказа сохранены.

## Что было проверено

| Маршрут | Результат |
| --- | --- |
| Публичный `backend-api/share` штатной утилитой | HTTP `403` |
| Публичная HTML-страница штатной утилитой | HTTP `403` |
| Настроенный workspace network route | повторный тайм-аут соединения |
| Встроенный браузер Codex | не инициализировался из-за несовместимости локального WSL workspace URI |
| Текстовый reader gateway | HTTP `451` |
| Несколько публичных CORS/translation gateways | upstream `403`, `521` или `522`; содержимого беседы нет |

Адреса и учетные данные сетевых маршрутов в dossier не записывались. Полученные страницы отказа и пустые загрузки не добавлены в Git.

## Почему здесь нет реконструкции

Нельзя выдавать предположительный преданализ за текст shared-беседы. Даже если тема ссылки очевидно связана с книгой, неизвестны:

- исходный пользовательский запрос;
- тезисы и структура ответа;
- embedded Research, если он был;
- список источников и точные оговорки;
- возможные возражения, уточнения и последний, наиболее ценный блок беседы.

Поэтому текущие аналитические файлы dossier построены только по полному FB3 и явно обозначенному редакторскому синтезу. Ни одно утверждение в них не атрибутировано недоступному ChatGPT-преданализу.

## Как завершить включение

При восстановлении сетевого маршрута следует повторить:

```bash
make extract-chatgpt CHATGPT_SHARE_URL="https://chatgpt.com/share/6a6f1203-39c0-83eb-9914-a8ad3a798504"
```

Если ссылка останется недоступной, нужен экспорт или вложение видимого диалога от пользователя. После получения текста требуется:

1. сохранить видимый диалог и embedded Research отдельно;
2. составить manifest и хэши;
3. сопоставить тезисы преданализа с `03-Аналитические-конспекты-глав.md`;
4. дополнить, а не перезаписать `06-Аудит-тезисов-и-доказательности.md`;
5. проверить все источники преданализа независимо от уверенности формулировок;
6. обновить `09-Состояние-сохранения.md`, реестр и обратные ссылки;
7. провести повторный link/privacy/evidence-аудит перед коммитом.

## Редакторская граница

Отсутствие преданализа не уменьшает полноту локальной обработки самой книги: все десять глав, служебные разделы, примечания, изображения и библиография сохранены и проверены. Оно ограничивает только независимый второй ракурс. До его получения пакет следует считать полным по FB3 и открытым по shared-беседе.
